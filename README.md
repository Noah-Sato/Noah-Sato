## What I'm working on

**[AdventuresApp](https://github.com/Noah-Sato/AdventuresApp)** is a social events app built with React Native, Expo and TypeScript on a Supabase backend. The parts I've enjoyed most are on the database side: row-level security policies, time-windowed photo uploads enforced in both the table and storage layers, and an Edge Function that issues chat tokens so the secret never reaches the client. Push notifications are in progress.
